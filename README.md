# 📊 Sales Analytics Dashboard

An interactive **Excel Sales Analytics Dashboard** developed to monitor and analyze sales performance across products, salespeople, regions, and time periods. The dashboard transforms raw sales data into clear visual insights using **Pivot Tables, Pivot Charts, Slicers, and KPI cards**.

## 🎯 Project Objective

The main objective of this project is to provide a simple and interactive view of sales performance and help identify:

* Overall sales performance
* Monthly sales trends
* Best and lowest-performing products
* Top and bottom-performing salespeople
* Regional sales performance
* Product quantity performance
* Changes in performance based on date, region, and product selection

## 💰 Key Performance Indicators

* **Total Sales:** 366

These KPIs provide a quick overview of the overall business performance.

## 📈 Dashboard Analysis

### 1. Monthly Sales Analysis

The dashboard includes a **Sales by Months** line chart to visualize sales amounts across different months and identify changes in monthly performance.

### 2. Regional Sales Analysis

Sales are analyzed across four regions:

* East
* North
* South
* West

The regional chart helps compare the sales contribution from each region.

### 3. Product Sales Analysis

The dashboard compares sales quantities for:

* Keyboard
* Monitor
* Mouse
* Printer
* Scanner
* Speaker

This makes it easy to understand which products are generating higher sales volumes.

### 4. Top & Bottom Products

The **Top 3 Selling Products** section highlights the products with the highest quantities sold, while the **Top 3 Less-Selling Products** section identifies products with lower sales quantities.

### 5. Salesman Performance

The Salesmen dashboard provides:

* Overall salesman performance
* Top 3 salesmen
* Top 3 less-performing salesmen
* Individual sales amount comparison

This allows performance differences between salespeople to be viewed clearly.

## 🎛️ Interactive Dashboard Filters

The dashboard contains interactive slicers for:

* **Date**
* **Region**
* **Item**

Users can select different combinations of filters and dynamically analyze the corresponding sales information.
